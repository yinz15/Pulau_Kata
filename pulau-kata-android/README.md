# Pulau Kata Android project

This Android app opens the live Pulau Kata site at:

`https://pulau-kata-year-one-adventure.teaservideo1.chatgpt.site/`

## Build from GitHub

1. Create a new GitHub repository.
2. Upload the **contents** of this folder, including `.github`, `app`, and the Gradle files.
3. Open **Actions**, select **Build Android APK**, then choose **Run workflow**.
4. Download `pulau-kata-debug-apk` from the successful run's Artifacts section.

## Identity

- App name: Pulau Kata
- Package ID: `com.nilampublication.pulaukata`
- Minimum Android version: Android 6.0

The game requires internet access because it loads from the published website. The app will show an error message if it cannot reach the site.
